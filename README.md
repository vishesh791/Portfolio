# Vishesh Kumar — Portfolio Website

A responsive engineering portfolio built with Next.js, React, and Lucide icons. It presents Vishesh Kumar’s resume keywords and identifies Dev Kumar as a collaborator on the three Arduino projects. Shukriya is listed separately as a software project.

## Run locally

1. Install Node.js (LTS) if it is not installed.
2. Open this folder in VS Code.
3. In the terminal, run:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000

## Before publishing

- Verify the resume URL and contact email/phone in `app/page.jsx`.
- Arduino Pac-Man and both Tic-Tac-Toe projects are identified as collaborative builds by Vishesh Kumar and Dev Kumar; ensure this accurately reflects both contributions.
- Resume keywords represented include Testing & Validation, multimeter, oscilloscope, DC source/electronic load, input/output checks, hardware debugging, troubleshooting, test plans, technical documentation, Arduino Nano, C/C++, TV Out library, composite video output, touch-display integration, circuit assembly, soldering/desoldering, component integration, Arduino IDE, Serial Monitor, iterative prototyping, and game logic.
- Add your LinkedIn and GitHub URLs if you want social links shown.
- Add a public link for the Shukriya project if available.
- Check that each Google Drive project folder and all videos inside are viewable by anyone with the link.
- The Living Arcade is clearly described as a future concept, not a completed project.

## Deploy

Push this project to GitHub and import the repository into Vercel. The default Next.js settings should work.
